# Online Library Management System 📚

## Description
The **Online Library Management System** is a simple and intuitive web-based application to manage books in a library.  
It allows users to **add books, search by title, filter by availability, and view a dynamic book list**.  
This project is built using **HTML, CSS, JavaScript** (front-end) and can be integrated with **Spring Boot and MySQL** for backend and persistent storage.

The interface is **modern, responsive, and user-friendly**, with attractive cards, tables, and buttons.

---

## Features

- Add a new book with details: **Title, Author, Genre, Year, and Status**  
- Search books by **Title**  
- Filter books by **Availability (Available/Issued)**  
- View **dynamic book list** in a styled table  
- Edit or Delete books (if backend integration is added)  
- Fully **responsive layout** for mobile and desktop  

---

## Tech Stack

- Frontend: `HTML`, `CSS`, `JavaScript`  
- Backend (optional for full functionality): `Spring Boot`, `Java`, `MySQL`  
- Tools: `VS Code` / `IntelliJ IDEA`
